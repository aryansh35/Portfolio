# ⚡ Aryansh Gupta — Developer Portfolio

A cinematic, modern, and interactive portfolio website showcasing software development, DevSecOps, and web engineering projects. Built with high-performance animations, 3D card tilt physics, custom cursor spotlights, and a sleek dark aesthetic.

## ✨ Features

- 🎬 **Cinematic Netflix Preloader**: Smooth initial loading sequence.
- 🎯 **Interactive Cursor & Spotlight Beam**: Real-time cursor tracking and ambient radial glow across sections.
- 🎴 **3D Holographic Tilt Card**: Physics-driven 3D tilt and glare reflections powered by GSAP.
- 💻 **Project Showcase**: Rich interactive project cards with live links and tech tags.
- 🛠️ **Skills & Expertise Matrix**: Categorized tech stacks spanning Frontend, Backend, DevSecOps, and Security.
- 📬 **Interactive Contact Section**: Direct contact channels, social links, and messaging.
- 📱 **Fully Responsive**: Optimized for desktop, tablet, and mobile displays.

---

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Bundler**: [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animation & Physics**: [GSAP](https://greensock.com/gsap/) & [Framer Motion](https://www.framer.com/motion/)
- **Scroll Effects**: [AOS (Animate On Scroll)](https://michalsnik.github.io/aos/)

## 🚀 Getting Started

### Prerequisites

Ensure you have [Node.js](https://nodejs.org/) (version 18+ recommended) installed.

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/aryansh35/Portfolio.git
   cd Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the local development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```

5. **Preview production build:**
   ```bash
   npm run preview
   ```
